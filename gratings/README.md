# Gratings

A WebGL stimulus page for showing gratings (sinusoidal, square, disks) with the controls of `dat.gui`.
Open `gratings.html` from a web server (for example `python3 -m http.server`).

This was copied from the `fish` repository (`gratings.html`, `css/`, `js/`, `external/`); the other pages
there (preferential, random dots, sweep and so on) stay in that repository.
